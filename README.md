# Wazpp

Wazpp is a WhatsApp automation platform that helps businesses communicate smarter, faster, and at scale.

**Chat to Grow.**

## Website

This repository contains the Wazpp marketing website:

- `index.html` - Home page and animated hero
- `features.html` - Platform capabilities
- `about.html` - Brand story and vision
- `contact.html` - Contact form and conversion page
- `styles.css` - Shared responsive styling
- `script.js` - Mobile navigation, active links, status text, and contact form behavior
- `web-logo.png` - Wazpp horizontal logo

## Run locally

The site is static and requires no build step. Open `index.html` directly in a browser, or serve the folder with any static web server.

For example, with Node.js:

```powershell
npx serve .
```

## Deploy

GitHub Pages deployment is configured in `.github/workflows/pages.yml`. Pushes to `main` trigger the workflow.

Live URL:

<https://wazpp.github.io/home/>

## Brand

Wazpp combines a green-and-black visual identity with the message **Chat to Grow**, representing connected conversations, automation, trust, and scalable business communication.
